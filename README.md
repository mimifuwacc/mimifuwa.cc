# 🌸 mimifuwa.cc

**mimifuwa.cc** は、デザインとテクノロジーの両面から制作物を紹介する**個人ポートフォリオサイト**です。  
やわらかいビジュアルとミニマルなUIを基調に、作品・スキル・活動履歴を直感的に閲覧できるよう設計しています。

---

## 🧭 Overview

このサイトは、クリエイター／エンジニアとしての活動をまとめた**自己紹介・作品展示のプラットフォーム**です。  
最新のWeb技術を活用し、パフォーマンスとデザインの両立を追求しています。

---

## ✨ Features

- 🖼️ 作品ギャラリー（プロジェクト一覧・詳細ページ）
- 📜 自己紹介・スキル紹介セクション
- 📬 問い合わせフォーム
- 🌙 ダークモード対応（オプション）
- 📱 レスポンシブデザイン（スマートフォン最適化）
